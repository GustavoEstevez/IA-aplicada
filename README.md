# RTSP Scout · Escritorio

Queda una sola versión: [PySide6](desktop_pyside6/README.md). Primero ejecutá `desktop_pyside6\Instalar.bat`; después iniciá con `desktop_pyside6\Iniciar.bat`.

La captura RTSP y la detección de rostros se procesan con Python/OpenCV. Intenta CUDA, luego OpenCL y usa CPU automáticamente si la GPU no es compatible.
